# Smoke-Shack

1. Add this repository to the Home Assistant Apps store, then install Smoke-Shack.
2. Start the app after installation.
3. Open Smoke-Shack from the Home Assistant sidebar.
4. On first run, Smoke-Shack reads your grill entities from Home Assistant.
5. Cook data and photos stay in the app's `/data` directory.
6. Home Assistant backups include the app's data.
